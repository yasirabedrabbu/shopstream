# ShopStream

Multi-vendor e-commerce platform with zero-oversell flash sales and live vendor dashboard.

## Stack
- Java 25 + Spring Boot 3.5 (core API)
- Rust + Axum (inventory engine)
- Next.js (storefront + dashboards)
- SvelteKit (embeddable widgets)
- PostgreSQL 16 on Neon
- Redis on Upstash

## Status
Backend API complete. Frontend in progress.
